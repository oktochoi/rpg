# 1. Chapter 1의 최종 스토리 목표

Chapter 1은 아래 한 문장으로 설명되어야 한다.

> **루엔 주변의 고블린 이상 이동을 추적하던 신참 모험가가, 폐허의 왕실 봉인이 최근 누군가에 의해 훼손되었다는 사실을 발견하고, 그 여파가 북문 너머까지 이어지고 있음을 알게 된다.**

Chapter 1 전체가 다음 인과관계를 가져야 한다.

```text
루엔의 이상 징후
↓
고블린의 비정상적인 이동
↓
숲의 푸른 마력 흔적
↓
고블린들이 폐허 방향의 이상 현상을 피해 이동했음
↓
폐허에 최근 사람이 접근한 흔적
↓
왕실 봉인 시설 발견
↓
봉인은 이미 누군가에 의해 훼손되어 있음
↓
Guardian 각성
↓
누가 봉인을 건드렸는지는 아직 알 수 없음
↓
북문 너머에서도 동일한 푸른 현상 발생
↓
Chapter 2
```

- [x] 위 흐름이 실제 플레이에서 이해되는지 확인한다.
- [x] 각 단계가 다음 단계의 원인이 되거나 다음 질문을 만들어야 한다.
- [x] “갑자기 세리아가 폐허 퀘스트를 준다”는 느낌이 없어야 한다.
- [x] “고블린 퀘스트와 폐허 퀘스트가 별개”라는 느낌이 없어야 한다.

# 2. Chapter 1 Story Bible 확정

작업 중 아래 설정을 기준으로 한다.

## 중심 질문

> 누가 루엔의 왕실 봉인을 최근에 건드렸는가?

- [x] Chapter 1에서는 이 질문의 완전한 답을 공개하지 않는다.

## 초반에 플레이어가 아는 것

- 고블린의 수와 행동이 평소와 다르다.
- 북쪽 교역이 불안정하다.
- 숲과 북쪽에서 이상한 소문이 돌고 있다.

## 중반 Reveal

> 고블린이 단순히 늘어난 것이 아니라 폐허 쪽 이상 현상 때문에 평소 영역에서 밀려나고 있다.

## 후반 Reveal

> 폐허는 왕실과 관련된 봉인 시설이며, 누군가 최근 봉인을 먼저 훼손했다.

## Chapter 1에서 답하지 않는 것

- 누가 봉인을 훼손했는가?
- 왜 봉인을 훼손했는가?
- 봉인의 정확한 최종 목적은 무엇인가?

## 마지막 Hook

> 북문 너머에서도 폐허와 동일한 푸른 현상이 나타났고, 경비 초소와 연락이 끊겼다.

- [x] Chapter 1 종료 시 이 Hook이 명확하게 전달되도록 한다.

# 4. P0 — 가짜 선택지 제거

## 4-1. `ANCIENT_RUINS_DISCOVERY`

현재 선택:

- 마법석에 손을 댄다
- 주변부터 조사한다

두 선택이 모두 동일하게 Guardian 각성으로 이어지더라도 **중간 결과가 달라야 한다.**

### 권장

#### 마법석에 손을 댄다

- [x] 즉시 Guardian 각성.
- [x] 사전 조사 Fact는 획득하지 못함.
- [x] 위험 감수형 선택으로 처리.

#### 주변부터 조사한다

- [x] `RUINS_MAGIC_RESIDUE` 또는 이에 해당하는 “최근 접근/훼손 흔적” Fact 획득.
- [x] 최근 누군가 먼저 들어왔다는 정보를 먼저 얻음.
- [x] 이후 Guardian 각성.

### 완료 조건

- [x] 둘 다 메인 진행은 가능.
- [x] 조사 여부가 후속 보고 대사 또는 Fact 상태에 반영됨.

현재 선택이 다음과 유사하다면:

- 기록한다
- 파편을 챙긴다

전부 같은 후속 장면으로 가더라도 상태 차이를 남긴다.

- [x] 후속 세리아/레온 대사에서 최소 하나 이상의 차이를 보인다.

## 4-3. `SERIA_FINAL_REPORT`

현재 “모두 말한다 / Guardian부터 / 봉인부터”처럼 **순서만 다른 선택**이라면 제거한다.

대신 “무엇을 공개할 것인가”로 바꾼다.

가능한 구조:

- [x] 조사한 내용을 전부 공개한다.

**2~3개의 의미 있는 선택이면 충분하다.**

- [x] 최소 3개의 단서는 mainline에서 반드시 노출한다.

# 8. P1 — 세리아 의뢰의 동기를 강화

대상:

- `src/game/npc/npc-profiles.ts`
- `src/game/story/story-scene-definitions.ts`

현재 세리아가 단순히 “이상한 마력이 있으니 조사해달라” 정도라면 동기를 강화한다.

세리아의 입장:

> **봉인을 연구해야 다음 사고를 막을 수 있다. 진실을 알아야 대응할 수 있다.**

- [x] 세리아가 플레이어보다 먼저 같은 계열의 푸른 마력 파동을 관측했다는 설정을 기존 대사에 반영한다.
- [x] 플레이어가 숲에서 가져온 정보와 세리아의 관측 정보가 연결되면서 폐허 의뢰가 열리게 한다.
- [x] 세리아가 직접 폐허로 가지 않는 이유를 **하나**로 확정한다.
