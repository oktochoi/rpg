# Docs

운영 문서는 이 세 개만 기준으로 쓴다.

| 파일 | 역할 |
| --- | --- |
| [`CURRENT_STATE.md`](./CURRENT_STATE.md) | 지금 게임이 어떤 상태인지 |
| [`CHANGED.md`](./CHANGED.md) | 최근에 뭐가 바뀌었는지 |
| [`TODO_NEXT.md`](./TODO_NEXT.md) | 앞으로 뭘 바꿔야 하는지 |

나머지 문서는 역할별로 나눈다.

| 폴더 | 내용 |
| --- | --- |
| [`design/`](./design) | 설계. `GAME_DESIGN.md`, `ARCHITECTURE.md`, `ASSETS.md`, `TASKS.md` |
| [`plans/`](./plans) | 진행 계획과 체크리스트 |
| [`notes/`](./notes) | 챕터 1 플레이 기록, 갭 정리 |
| [`images/`](./images) | README용 스크린샷 |
| [`art-reference/`](./art-reference) | 원본 시트. 런타임에 로드하지 않는다 |
